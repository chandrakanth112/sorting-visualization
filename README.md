# Sorting Visualization

Want to understand how sorting algorithms actually work? This project shows you exactly that with interactive animations!

I've built visualizations for five classic sorting algorithms:
- **Bubble Sort** - The simple approach that compares neighbors repeatedly
- **Insertion Sort** - Like sorting playing cards in your hand
- **Selection Sort** - Find the smallest and move it to the front
- **Quick Sort** - Divide and conquer with a pivot
- **Merge Sort** - Split everything and merge it back sorted

You can watch each algorithm in action, see how many comparisons it takes, and understand why some are faster than others. Great for learning or teaching!
